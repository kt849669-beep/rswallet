# RS Wallet — Project State

Working notes for anyone (human or AI) picking this project up.

## Identity

- **Brand:** RS Wallet (display form `RS Wallet`; also written `Rs Wallet` / `RsWallet`)
- **Domain:** `rswallet.online` — the single canonical domain, read from `NEXT_PUBLIC_SITE_URL`
- **Market:** India (`en-IN`, `geo.region: IN`)
- **Stack:** Next.js App Router + React, Supabase (REST) for data and storage, deployed on Vercel

## Structure

The app is a single Next.js project. There is exactly one implementation — `app/` for routes and
API handlers, `components/` for UI, `lib/` for the Supabase client and admin session auth,
`database/` for SQL. Nothing else is live.

## Routes

- `/` — RS Wallet login. Public and indexed. The only indexed page; carries all site SEO.
- `/home` — user dashboard. `noindex`.
- `/admin/login`, `/admin/dashboard` — admin panel. `noindex`, blocked in `robots.txt`.
- `/api/auth/login`, `/api/auth/mpin` — user auth.
- `/api/admin/login|logout|overview|resource|upload` — admin operations.
- `/login` → `301` → `/`.

## SEO

All public SEO is on the login page and is **invisible** — head metadata and JSON-LD only. The
visible UI is the login screen exactly as designed; there is no marketing or FAQ content below the
form. Nothing is generated by a script — edit the source directly:

- `app/layout.js` — title template, description, keyword set, Open Graph, Twitter, icons,
  manifest link, `en-IN` alternates, geo meta, theme colour.
- `app/page.js` — JSON-LD graph: `WebSite`, `Organization`, `WebPage`, `SoftwareApplication`.
  Do **not** add `FAQPage`, `HowTo` or `Review` schema here — Google requires structured data to
  match content that is visible on the page, and this page shows only the login form.
- `public/robots.txt` — allows `/`, blocks `/admin`, `/home`, `/api`.
- `public/sitemap.xml` — one URL (`/`). Bump `lastmod` when home page content changes.
- `public/manifest.json` — PWA install metadata, so "add to home screen" behaves like an app.

Target keywords: Rs wallet, Rs Wallet login, Rs wallet app, Rs wallet apk, RS Wallet official app,
RS Wallet customer support, RS Wallet India, Rs wallet UPI, Rs wallet USDT.

## Supabase

Unchanged and authoritative. `lib/supabase-rest.js` wraps the REST endpoint; every table read and
write goes through the API routes under `app/api/`. Schema, RLS policies, triggers, storage buckets
and seed data live in `database/*.sql`. Do not switch the data layer.

## Admin panel

Tabs: overview, users, sliders, banners, video, telegram, notifications, trash, activity.
Slider images and reward banners are uploaded from the panel into Supabase Storage.
Sessions are cookie-based and signed with `ADMIN_SESSION_SECRET`.

## Conventions

- Local dev environment is Windows / PowerShell.
- Design language: teal (`--accent: #167d70`, `--accent-dark: #0d4f49`), mobile-first, max width 590px.
- All styles live in `app/globals.css`. No CSS framework.
- Keep `/home` and `/admin/*` `noindex` — only `/` should ever be indexed.
