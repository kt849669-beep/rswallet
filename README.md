# RsWallet

RsWallet is a mobile-first Next.js application with a user login/dashboard flow and a protected administration panel.

## Routes

- `/` — user login
- `/home` — protected user dashboard
- `/admin/login` — administrator login
- `/admin/dashboard` — administrator dashboard and media controls

## Local development

Copy `.env.example` to `.env.local`, provide the required values, then run:

```bash
npm install
npm run dev
```

The app opens at `http://localhost:3000`.

## Validation

```bash
npm run build
npm run test:seo
npm run test:seo-monitor
```

Slider images and reward banners are managed from the admin panel and stored in Supabase Storage. Public SEO pages, `robots.txt`, and `sitemap.xml` are generated by `npm run generate:seo`.
